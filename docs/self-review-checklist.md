# セルフレビューチェックリスト

PR 作成前に以下を確認すること。

## ブランチ

- [ ] `develop` から派生している
- [ ] ブランチ名が `feature/{issue番号}-{概要}` または `fix/{issue番号}-{概要}` 形式

## PR

- [ ] 1 タスク = 1 PR になっている
- [ ] PR の説明に変更内容が記載されている

## 命名規則

- [ ] クラス名: `PascalCase`（例: `UserSettings`）
- [ ] 変数名・メソッド名: `camelCase`（例: `displayName`）
- [ ] ファイル名: `snake_case`（例: `user_settings.dart`）
- [ ] Bool 型の変数: `is` / `has` / `can` 接頭辞（例: `isEnabled`）
- [ ] Provider 名: `{サービス名}Provider`（例: `authServiceProvider`）

## 共通化

- [ ] 複数画面で使うコードは `core/` に配置している
- [ ] モジュール固有のコードはモジュール内に配置している

## コメント

- [ ] `// TODO:` 形式で未完了タスクを記載している
- [ ] 複雑なロジックには意図を説明するコメントがある
- [ ] 不要なコメントアウトされたコードが残っていない

## コード品質

- [ ] ネストが 2 重以内に収まっている
- [ ] メソッドが 40 行以内に収まっている
- [ ] 強制アンラップ（`!`）を使用していない
- [ ] タイポがない
- [ ] `dart format` でフォーマット済み
- [ ] `flutter analyze` でエラー 0 件
- [ ] `dart run custom_lint` でエラー 0 件
- [ ] テストが全パスしている
