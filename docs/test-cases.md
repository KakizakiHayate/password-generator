# テストケース一覧

> マストで必要なテストケースのみ記載。テスト対象は Model / Service / ViewModel 層。

---

## F-01: パスワード生成エンジン

| ID | テストケース | 期待結果 |
|----|-------------|---------|
| T-1.1 | デフォルト設定（16文字、全文字種ON）で生成する | 16文字のパスワードが生成され、大文字・小文字・数字・記号が各1文字以上含まれる |
| T-1.2 | 文字数を4、全文字種ONで生成する | 4文字のパスワードが生成され、各文字種が1文字ずつ含まれる |
| T-1.3 | 文字数を128で生成する | 128文字のパスワードが生成される |
| T-1.4 | 大文字のみONで生成する | A-Zのみで構成されたパスワードが生成される |
| T-1.5 | 最後の1つの文字種をOFFにしようとする | OFFにできず、最低1つのトグルがON状態を維持する |
| T-1.6 | 同じ設定で2回生成する | 異なるパスワードが生成される（乱数性の確認） |

## F-02: 紛らわしい文字の除外

| ID | テストケース | 期待結果 |
|----|-------------|---------|
| T-2.1 | 除外ONで生成する（全文字種ON、十分な文字数） | `o O 0 l I 1 \| \` ' "` がパスワードに含まれない |
| T-2.2 | 除外ON + 数字のみONで生成する | `0` と `1` が除外され、`2-9` のみで構成される |

---

## F-03: 特殊文字のカスタム選択

| ID | テストケース | 期待結果 |
|----|-------------|---------|
| T-3.1 | `! @ #` の3記号のみONにして記号トグルONで生成する | パスワードの記号部分が `! @ #` のみで構成される |
| T-3.2 | 全記号OFFの状態でモーダルの「完了」を押す | 「記号を1つ以上選択してください」とエラーが表示され、モーダルが閉じない |
| T-3.3 | 「すべて選択」を実行する | 全28記号がONになる |
| T-3.4 | 全記号ON状態で「すべて解除」を実行する | 全記号がOFFになる |

## F-04: 設定の自動保存

| ID | テストケース | 期待結果 |
|----|-------------|---------|
| T-4.1 | 初回起動時にsettingsドキュメントを読み取る | デフォルト値（文字数16、全トグルON、除外OFF、全記号ON）で設定が作成される |
| T-4.2 | 設定を変更する（例: 文字数を20に変更） | Firestoreに即時保存される |
| T-4.3 | 保存済み設定を復元する | 保存時の設定値が正しく復元される |

## F-07: パスワード強度インジケーター

| ID | テストケース | 期待結果 |
|----|-------------|---------|
| T-7.1 | エントロピーが 27 bit のパスワードの強度を判定する | `weak`（弱い）が返される |
| T-7.2 | エントロピーが 28 bit のパスワードの強度を判定する | `fair`（普通）が返される |
| T-7.3 | エントロピーが 36 bit のパスワードの強度を判定する | `strong`（強い）が返される |
| T-7.4 | エントロピーが 60 bit のパスワードの強度を判定する | `veryStrong`（非常に強い）が返される |
| T-7.5 | デフォルト設定（16文字、全文字種ON）のエントロピーを計算する | 約 105 bit（`veryStrong`）が返される |
| T-7.6 | 解読推定時間を計算する（60 bit、攻撃速度 10⁹回/秒） | 約「3万6千年」と表示される |
