# 画面一覧

> **対象フェーズ: フェーズ1（MVP）のみ**

---

## UI構成

| 画面名 | パス | 表示方法 | 説明 |
|-------|------|---------|------|
| メイン画面 | `/` | 常時表示 | パスワード生成・表示・コピー・設定をすべて1画面で完結 |
| アプリ情報画面 | — | モーダルシート | アプリ情報、プライバシーポリシー |
| 記号カスタム選択 | — | モーダルシート | 「すべて選択/すべて解除」ボタン + チップグリッドで記号の個別ON/OFF |

```
┌──────────────┐
```

- 各モーダル → メイン画面: 「完了」ボタンまたはスワイプダウンで閉じる

### レイアウトの構成要素

| # | エリア | 内容 | HIG根拠 |
|---|-------|------|---------|
| 1 | **ナビゲーションバー** | アプリタイトル + 設定アイコン | HIG 9.2: ナビゲーションバーにタイトル表示 |
| 2 | **パスワード表示エリア** | 生成されたパスワード（タップでコピー）| HIG 1: 明確さ — 等幅フォントで1文字ずつ判別しやすく |
| 3 | **強度表示** | 4分割セグメントバー + テキスト + 解読推定時間 | HIG 10.2: 色+テキスト+形状の3要素 |
| 4 | **候補リスト** | 折りたたみセクション（デフォルト収納）| HIG 1: 敬意 — 通常時は情報量を抑える |
| 5 | **文字数スライダー** | CupertinoSlider + 現在値の表示 | HIG 3.3: リアルタイムの値表示 |
| 6 | **文字種トグル群** | CupertinoSwitch × 4 + ラベル | HIG 3.2: 左にラベル、即時反映 |
| 7 | **除外・カスタム設定** | CupertinoSwitch + モーダルへの導線 | HIG 3.6: サブタスクはモーダルシートで |
| 8 | **生成ボタン** | CupertinoButton.filled | HIG 3.1: 1画面にFilledは1つ |

### 配置の根拠（HIG 人間工学）

| ゾーン | 配置 | 理由 |
|-------|------|------|
| **画面上部** | パスワード表示 + 強度表示 | 最も視認性が高い。ユーザーの目が最初に行く場所 |
| **画面中央** | スライダー + トグル群 | 指が届きやすく、設定操作が快適 |
| **画面下部** | 「生成する」ボタン | 最も指が届きやすい場所に最頻アクションを配置 |

## 記号カスタム選択のレイアウト

### ワイヤーフレーム

```
┌──────────────────────────────────────┐
│               記号の選択       [完了]  │  ← CupertinoNavigationBar
│                                      │
│  [すべて選択]                         │  ← 全記号ON時は「すべて解除」に切替
│                                      │
│  ┌──────────────────────────────┐    │
│  │ [!] [@] [#] [$] [%] [^] [&] │    │  ← チップグリッド
│  │ [*] [(] [)] [-] [_] [=] [+] │    │     タップで個別ON/OFF
│  │ [[] []] [{] [}] [;] [:] [,] │    │     ON: アクセントカラー背景
│  │ [.] [<] [>] [?] [/] [~] [|] │    │     OFF: グレー背景
│  └──────────────────────────────┘    │
│                                      │
└──────────────────────────────────────┘
```

- **表示方法**: モーダルシート（画面下部からスライドアップ）
- **チップグリッド**: 常に操作可能。タップで個別にON/OFFできる
- **すべて選択/すべて解除**: 全記号がONの場合は「すべて解除」、それ以外は「すべて選択」を表示
- **閉じ方**: 「完了」ボタンまたはスワイプダウン
