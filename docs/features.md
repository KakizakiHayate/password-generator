## 詳細

### F-01: パスワード生成エンジン

- **概要**: 文字数と文字種を指定し、暗号学的に安全な乱数でパスワードを生成する。アプリ起動時に自動生成し、ユーザーが即座にコピーできる状態にする
- **ユーザーストーリー**: パスワードが必要なユーザーとして、アプリを開いたらすぐに安全なパスワードが表示されてほしい。設定を変えたら再生成して、条件に合ったパスワードを得たい
- **受け入れ条件**:
  - [ ] CupertinoSlider で文字数を指定できる（範囲: 4〜128、デフォルト: 16）
  - [ ] 文字種トグル（CupertinoSwitch）で以下を個別にON/OFFできる
    - 大文字 (A-Z)
    - 小文字 (a-z)
    - 数字 (0-9)
    - 記号（F-03で選択された記号）
  - [ ] 最低1つの文字種がONであること。最後の1つの文字種はOFFにできないよう防止する（エラー状態を未然に防ぐ）
  - [ ] 有効にした文字種から各1文字以上を必ず含める（例: 大文字と数字がONなら、結果に大文字・数字が各1文字以上含まれる）
  - [ ] 乱数生成に `Random.secure()` を使用する（暗号学的に安全）
  - [ ] アプリ起動時に保存済み設定（初回はデフォルト設定）で自動生成する
  - [ ] 「生成する」ボタン（CupertinoButton.filled）で再生成できる

---

### F-02: 紛らわしい文字の除外

- **概要**: 手書きメモ時に判別しにくい文字をワンタップで一括除外する
- **ユーザーストーリー**: パスワードを紙に控えるユーザーとして、oと0、lと1のように見分けがつかない文字を除外したい。メモを見返したときに正確に入力できるようにしたい
- **受け入れ条件**:
  - [ ] CupertinoSwitch 1つで以下の文字を一括除外できる: `o O 0 l I 1 | ` `` ` `` `' "`
  - [ ] デフォルト: OFF（除外しない）
  - [ ] ONにした状態で生成すると、上記の文字がパスワードに含まれない
  - [ ] 除外設定は F-04（設定の自動保存）の対象に含まれる

---

### F-03: 特殊文字のカスタム選択

- **概要**: サイトやサービスごとに異なる記号制約に対応するため、使用する記号を個別に選択できる
- **ユーザーストーリー**: 特定の記号しか使えないサービスのアカウントを作成するユーザーとして、使える記号だけを選んでパスワードを生成したい
- **受け入れ条件**:
  - [ ] メイン画面の「記号をカスタム選択」タップでモーダルシートを表示する
  - [ ] 対象記号をチップグリッドとして配置し、タップで個別にON/OFFできる
  - [ ] 対象記号: `! @ # $ % ^ & * ( ) - _ = + [ ] { } ; : , . < > ? / ~ |`
  - [ ] 「すべて選択」ボタンで全記号をONにできる。全記号がONの場合は「すべて解除」ボタンに切り替わる
  - [ ] 文字種トグル（F-01）で記号がONのとき、ここで選択された記号のみが使用される
  - [ ] モーダルを閉じる際に1つ以上の記号が選択されている必要がある。0個の状態で「完了」を押した場合、「記号を1つ以上選択してください」とエラーを表示し、モーダルを閉じさせない
  - [ ] 選択状態は F-04（設定の自動保存）の対象に含まれる
  - [ ] モーダルシートはスワイプダウンまたは「完了」ボタンで閉じる

---

### F-04: 設定の自動保存

- **概要**: アプリを閉じても前回の生成設定を保持し、再起動時に同じ設定で即座に使える
- **ユーザーストーリー**: 毎回同じ条件でパスワードを生成するユーザーとして、アプリを開くたびに設定し直す手間を省きたい
- **受け入れ条件**:
  - [ ] Firestore の `settings/{userId}` ドキュメントに以下の設定を保存する（詳細は [data-model.md](data-model.md) 参照）
    - 文字数（int）
    - 大文字トグル（bool）
    - 小文字トグル（bool）
    - 数字トグル（bool）
    - 記号トグル（bool）
    - 紛らわしい文字の除外トグル（bool）
    - カスタム記号の選択状態（Map<String, bool>）
  - [ ] 設定変更時に自動保存する（保存ボタン不要）
  - [ ] アプリ再起動時に保存済み設定を復元する
  - [ ] 初回起動時はデフォルト値を使用する

---

### F-05: ワンタップコピー

- **概要**: 生成されたパスワードをタップするだけでクリップボードにコピーする
- **ユーザーストーリー**: パスワードを他のアプリに貼り付けたいユーザーとして、タップ1回でコピーしたい
- **受け入れ条件**:
  - [ ] 生成されたパスワード表示エリアをタップでクリップボードにコピーできる
  - [ ] コピー完了時に触覚フィードバック（HapticFeedback）を発生させる
  - [ ] コピー完了時にパスワード表示エリアが一時的に「コピーしました」に切り替わり、1〜2秒後に元のパスワード表示に戻る（インラインフィードバック）

---

### F-06: 複数候補の一括生成

- **概要**: 1回のタップで5件のパスワード候補を一覧表示し、好みの候補を選んでコピーできる
- **ユーザーストーリー**: 複数の候補から選びたいユーザーとして、一度に複数のパスワードを見比べて、気に入ったものをコピーしたい
- **受け入れ条件**:
  - [ ] メイン画面内に「他の候補を見る ▼」の折りたたみセクションを配置する
  - [ ] タップすると同一画面内で5件の候補リストが展開される
  - [ ] 各候補にパスワード文字列（等幅フォント）と個別のコピーボタンを配置する
  - [ ] コピー時の挙動は F-05（ワンタップコピー）と同様（触覚・視覚フィードバック）
  - [ ] 再生成ボタンで全候補を一括リフレッシュできる
  - [ ] メインの「生成する」ボタン（F-01）押下時にも全候補が連動して再生成される
  - [ ] 再度「他の候補を見る ▲」タップで折りたたみ（収納）できる
  - [ ] 展開時にスクロールが必要になる場合、パスワード表示エリアは画面上部に留まるようにする

---

### F-07: パスワード強度インジケーター

- **概要**: 生成されたパスワードのエントロピー（ビット数）を計算し、強度と解読推定時間を視覚的に表示する
- **ユーザーストーリー**: セキュリティに不安があるユーザーとして、生成されたパスワードがどれくらい安全なのかを直感的に理解したい
- **受け入れ条件**:
  - [ ] パスワードのエントロピー（ビット数）を計算する
  - [ ] 強度レベルの閾値: < 28bit: 弱い / 28〜35bit: 普通 / 36〜59bit: 強い / 60bit〜: 非常に強い
  - [ ] 4分割のセグメントバーで強度を視覚的に表示する（4段階: 弱い / 普通 / 強い / 非常に強い）。強度レベルに応じて左から点灯数が増える（weak=1個, fair=2個, strong=3個, veryStrong=4個）
  - [ ] 点灯セグメントはすべてそのレベルの色で統一表示する（赤 → オレンジ → 黄 → 緑）
  - [ ] セグメントバーの横に強度テキストラベルを表示する（例: 「強い」）
  - [ ] 解読推定時間を日本語で表示する（例: 「総当たりで解読するのに約3兆年」）。攻撃速度の前提: 10億回/秒（1×10⁹）
  - [ ] 解読推定時間は最大単位1つで簡潔に表示する（例: 「1秒未満」「約3時間」「約5日」「約3万6千年」「約3兆年」）。使用単位: 秒・分・時間・日・年
  - [ ] 色 + テキスト + バー形状の3要素で伝える（色だけに頼らない。HIGアクセシビリティ準拠）
  - [ ] パスワードが生成・再生成されるたびに強度表示を更新する
  - [ ] 表示テキストは平易な日本語を使用する（「エントロピー」ではなく「パスワードの強さ」）

---

### F-08: アプリ情報画面

- **概要**: アプリ情報とプライバシーポリシーへのアクセスを提供する
- **ユーザーストーリー**: アプリの情報やプライバシーポリシーを確認したいユーザーとして、アプリ内から簡単にアクセスしたい
- **受け入れ条件**:
  - [ ] メイン画面のヘッダーにある設定アイコンからモーダル表示（CupertinoPageScaffold）
  - [ ] ナビゲーションバーは「完了」ボタンのみ（「キャンセル」なし）
  - [ ] 「アプリについて」セクションにバージョン番号を表示する（`package_info_plus` で pubspec.yaml から自動取得）
  - [ ] プライバシーポリシーへのリンクを配置する（タップで外部URLに遷移）
  - [ ] モーダルシートはスワイプダウンまたは「完了」ボタンで閉じる

---

### F-09: アナリティクス

- **概要**: Firebase Analytics を使用してユーザー行動を計測し、改善に活用する
- **ユーザーストーリー**: 開発者として、ユーザーがどの機能をどれくらい使っているかを把握し、今後の改善に活かしたい
- **受け入れ条件**:
  - [ ] 以下のイベントを計測する
    - `password_generated`: パスワード生成回数
    - `password_copied`: パスワードコピー回数
    - `settings_changed`: 設定変更（変更の種類をパラメータに含む）
    - `app_opened`: アプリ起動回数
  - [ ] パスワード文字列は一切送信しない（イベント名と回数のみ）
  - [ ] App Store プライバシーラベルに「アナリティクス」を申告する

---

### F-10: アプリ内レビュー依頼

- **概要**: 適切なタイミングで控えめにApp Storeレビューを依頼し、評価数を増やす
- **ユーザーストーリー**: 開発者として、アプリを気に入ったユーザーにレビューを書いてもらい、App Storeでの信頼性を高めたい
- **受け入れ条件**:
  - [ ] in_app_review パッケージを使用する
  - [ ] 3回目のパスワード生成完了時にレビュー依頼を表示する
  - [ ] レビュー依頼は1回のみ表示する（表示済みフラグを Firestore の `users/{userId}` に保存）
  - [ ] ユーザーの操作を妨げない控えめな表示とする
